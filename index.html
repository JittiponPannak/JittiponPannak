เกี่ยวกับ

นาย จิตติภณ พานนาค เป็นนักศึกษาชั้นปีที่ 4 ณ สาขาวิชานวัตกรรมดิจิทัลเทคโนโลยี คณะนวัตกรรมดิจิทัลเทคโนโลยี มหาวิทยาลัยรังสิต มีความสนใจในการพัฒนาซอฟต์แวร์ ทั้งในด้านเว็บ มือถือ และ Blockchain

ในเวลาว่าง ผมได้ศึกษาระบบและออกแบบ Prototype เกมใน Godot Engine, ศึกษาภาษาโปรแกรมมิ่งที่ผมสนใจ และฝึกใช้งานเครื่องมือ AI Agent ต่างๆ เช่น ChatGPT, Claude, Gemini, GitHub Copilot เพื่อช่วยในการพัฒาซอฟต์แวร์ โดยเน้นการพึ่งพา AI Agent ให้พอประมาณ และไม่มากจนเกินไป (ถึง AI และการ Vibe Coding กำลังมาแรง แต่ค่าใช้จ่ายของ Token ที่สูงขึ้นทำให้การมีความรู้พื้นฐานนั้นสำคัญ)

ผมค่อนข้างมันใจในความสามารถทางด้วยภาษาอังกฤษของตนเอง ในระดับที่สามารถสื่อสารกับคนต่างชาติ และ ทำงานกับชาวต่างชาติได้
